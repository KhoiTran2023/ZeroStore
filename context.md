# ZeroStore context

ZeroStore is a free, self-hosted, open-source knowledge layer that keeps every AI agent on the latest truth about a company. It reads sources (Google Drive, GitHub, Linear), keeps a fact store current, and serves cited answers to agents over a read-only MCP server with tokens and access levels.

## Current state

- Repository seeded with the license, README and this file. Code lands in reviewable stages: core first, then sources, the librarian layers, and the web UI.
